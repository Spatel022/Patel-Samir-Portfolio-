SAM Lens – Product Asset Studio

A locally run, browser-based Amazon product research and asset management tool built to simplify product lookup, listing preparation and image workflows.

TypeScriptNode.jsExpressSQLiteHTML & CSS
  • Search products using ASINs or Amazon URLs across supported marketplaces.
  • View product information and download available product images.
  • Organise saved products in separate project workspaces.
  • Edit listing content and export data to CSV, Excel and JSON.
  • Manage image downloads, ZIP exports and search/download history.

Deployment: Runs locally on the user's computer at 127.0.0.1:5000. It is not a hosted public web app.

Source code is currently kept in a private GitHub repository.
