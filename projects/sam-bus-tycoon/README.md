# SAM BUS TYCOON 🚌

A responsive browser-based Indian bus company management simulator prototype.

## Play
Open `index.html` in a modern browser, or visit the GitHub Pages URL after enabling Pages for this repository.

## Prototype features
- Company dashboard with balance, fleet, routes and daily profit
- Buy and sell buses in the showroom
- Manage Gujarat routes: Bharuch–Surat, Bharuch–Vadodara, Vadodara–Ahmedabad and Surat–Ahmedabad
- Assign buses and start or pause services
- Hire staff and track payroll
- Advance in-game days and review the financial ledger
- Automatic local save using browser LocalStorage
- Responsive desktop and mobile layout

## Run locally
No build tools or installation required. Download this folder and open `index.html`.

## Notes
This is **v0.1 web prototype**, not yet a 3D driving game. Prices and operating figures are fictional game-balance values. Save data stays in the browser on the device where you play.
